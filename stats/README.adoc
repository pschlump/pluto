= stats

Online statistics and exact quantiles.

- Zero-value Accumulator with stable Welford updates and immutable Stats
  snapshots: count, sum, mean, min/max, population/sample variance/deviation.
- Merge combines finite or non-finite datasets without retaining observations.
- PairedAccumulator/PairedStats provide Pearson correlation and ordinary least-
  squares fits. LinearTransformation supports regular, horizontal, vertical,
  inverse, and NaN forms.
- Type-7 Quantile/Quantiles, Median, and Percentile, with copying and in-place
  variants. Multiple indexes share one deterministic introselect pass
  (median-of-three/ninther pivots, Hoare partition, descent only into ranges
  holding requested ranks, repeated median-of-five fallback after a depth
  budget); duplicate indexes and result order are preserved. Expected O(n)
  for a fixed index count; adversarial inputs cannot drive it quadratic.

Empty means/extrema and insufficient sample/correlation results are NaN; empty
sum is zero. Non-finite observations propagate NaN as documented by the API.
Accumulators are mutable and not internally synchronized; immutable snapshots
support concurrent reads. No `_ts` twin is provided.
