= comparable
:toc:

== Overview

`comparable` defines the two interfaces used throughout this module as
constraints on the element types of the generic data structures:

- `Comparable` — three-way comparison: `Compare(b Comparable) int`
  returns a negative value if `a < b`, zero if equal, positive if `a > b`.
- `Equality` — equality test: `IsEqual(b Equality) bool`.

Packages such as `avl_tree`, `binary_tree`, `dll`, `sll`, `hash_tab`,
`heap`, and `priority_queue` constrain their element type parameter with
one of these interfaces.

== Example

[source,go]
----
type Item struct{ Key int }

func (a Item) Compare(b comparable.Comparable) int { return a.Key - b.(Item).Key }
func (a Item) IsEqual(b comparable.Equality) bool  { return a.Key == b.(Item).Key }

var _ comparable.Comparable = Item{}
var _ comparable.Equality   = Item{}
----

== Complexity

Both interfaces are single-method contracts; the cost of an operation is
the cost of the implementing method, typically O(1).

== Thread Safety

The interfaces carry no state.  Thread safety depends entirely on the
implementing type and the data structure using it.
