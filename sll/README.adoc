= sll

A generic *singly linked list* — usable directly as a *stack*
(`Push`/`Pop`/`Peek` at the head), with O(1) tail insertion
(`InsertAfterTail`), value-based search and delete, and in-place
reversal.  For a doubly linked list with tail pops, positional access,
walking, trimming and concatenation, see link:../dll/[`dll`].

* Elements are stored and returned *by value* (`T`, not `*T`).
* Lists of types comparable with `==` (all scalars, strings, pointers,
arrays, and structs of comparable fields) need no equality function:
`sll.NewSll[int]()`.
* Any other type — or equality by a single field — takes a plain equality
function, with no interface to implement:
`sll.NewSllFunc(func(a, b Item) bool { return a.ID == b.ID })`.

The equality function is consulted *only* by `Search`, `Delete` and
`DeleteFound`.  The stack and positional operations never compare
elements.  Search probes are passed by value, so a probe only needs the
fields the equality function reads.

Runnable, tested copies of the examples live in
link:example_test.go[`example_test.go`] — they run under `go test` and appear
on pkg.go.dev.

== Operations

[options="header"]
|===
| Operation                                       | Description                                    | Complexity

| `Push` / `InsertBeforeHead`                     | Insert at the head                             | O(1)
| `InsertAfterTail`                               | Insert at the tail                             | O(1)
| `Pop`                                           | Remove and return the head                     | O(1)
| `Peek`                                          | Look at the head without removing              | O(1)
| `Search`                                        | Find the first element equal to a probe        | O(n)
| `Delete`                                        | Delete the first element equal to a probe      | O(n)
| `DeleteFound`                                   | Delete the element with a found element's data | O(n)
| `Reverse`                                       | Reverse in place, O(1) extra storage           | O(n)
| `Truncate`                                      | Remove all elements                            | O(1)
| `IsEmpty` / `Len` / `Length`                    | Size queries                                   | O(1)
| `Dump`                                          | One line per element, for debugging            | O(n)
| `Front`/`Current` + `Next`/`Done`/`Pos`/`Value` | Cursor iterator                                | O(n) total
| `IterateOver`                                   | `iter.Seq2[int, T]`, head to tail              | O(n)
|===

Note that `DeleteFound` — unlike in the `dll` package — is a value-based
re-search, not a direct splice: it removes the first element whose data
equals the found element's data, in O(n).

== Errors

Empty-list and not-found conditions are reported with errors (compare
with `errors.Is`), not panics:

[options="header"]
|===
| Error         | Meaning

| `ErrEmptySll` | pop/peek/`DeleteFound` on an empty list
| `ErrNotFound` | `Delete`/`DeleteFound` with no matching value
|===

== Usage

Stack:

[source,go]
----
stack := sll.NewSll[string]()
stack.Push("first")
stack.Push("second")
top, _ := stack.Peek()   // second
v, _ := stack.Pop()      // second
----

FIFO with tail insertion and head removal:

[source,go]
----
queue := sll.NewSll[int]()
queue.InsertAfterTail(1)
queue.InsertAfterTail(2)
head, _ := queue.Pop()   // 1 — first in, first out
----

Search and delete of a found element:

[source,go]
----
el, pos := list.Search(probe)  // element + position, or nil/-1
if el != nil {
    list.DeleteFound(el)
}
----

`SllElement.data` is an unexported `T`; use `GetData()` on the handle.

Iteration with the index:

[source,go]
----
for i, v := range list.IterateOver() {
    ...
}
----

== Panics

The package panics in exactly three situations — all programmer errors
with no sane fallback:

[options="header"]
|===
| Call | Why 

| `NewSllFunc(nil)` | nil equality function, caught at construction time 
| Insert-family on a nil `*Sll` | a nil list cannot store an element 
| Insert-family on a zero-value list | no equality function; the message names the constructors 
|===

The insert family is `InsertBeforeHead`, `InsertAfterTail` and `Push`.
Everything else tolerates a nil list and the zero value as an empty list.
