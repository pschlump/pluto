= A generics based Go Singly Linked List

A simple singly linked list (SLL) implemented with Go generics.  Each value is
stored as a pointer to the caller's data (`*T`), where `T` implements the
`comparable.Equality` interface (`IsEqual`).

The list keeps both head and tail pointers, so insertion at either end is O(1).
It supports both an old-style `Front`/`Next`/`Done` iterator and modern
Go 1.23+ range-over-func iterators (`IterateOver`, `IteratePtr`).

== Operations and Complexity

[cols="2,1,3",options="header"]
|===
| Operation | Complexity | Notes

| `NewSll`            | O(1) | Create an empty list.
| `IsEmpty`           | O(1) | True if the list is empty.
| `Length`            | O(1) | Number of elements.
| `Push` / `InsertBeforeHead` | O(1) | Prepend at the head.
| `InsertAfterTail`   | O(1) | Append at the tail.
| `Pop`               | O(1) | Remove and return the head element; `ErrEmptySll` if empty.
| `Peek`              | O(1) | Return the head element without removing it.
| `Search`            | O(n) | Head-to-tail search using `IsEqual`; returns the node and its index.
| `Delete`            | O(n) | Unlink a node returned by `Search`; `ErrNotFound` if not in the list.
| `Truncate`          | O(1) | Remove all elements.
| `Front` / `Current` iterator | O(1) per step | Old-style manual iterator.
| `IterateOver` / `IteratePtr` | O(n) full pass | Go 1.23+ range-over-func iterators.
|===

== Example

[source,go]
----
package main

import (
	"fmt"

	"github.com/pschlump/pluto/comparable"
	"github.com/pschlump/pluto/simple_sll"
)

type Name struct {
	First, Last string
}

func (a Name) IsEqual(x comparable.Equality) bool {
	if b, ok := x.(Name); ok {
		return a.First == b.First && a.Last == b.Last
	}
	panic("invalid type passed to IsEqual")
}

func main() {
	list := sll.NewSll[Name]()
	list.InsertAfterTail(&Name{First: "Ada", Last: "Lovelace"})
	list.Push(&Name{First: "Alan", Last: "Turing"})

	// Modern range-over-func iteration (Go 1.23+):
	for i, v := range list.IterateOver() {
		fmt.Printf("%d: %s %s\n", i, v.First, v.Last)
	}

	// Old-style iteration is still supported:
	for it := list.Front(); !it.Done(); it.Next() {
		fmt.Printf("at %d: %+v\n", it.Pos(), it.Value())
	}

	v, err := list.Pop() // removes "Alan Turing" (the head)
	_ = v
	_ = err
}
----

== Thread Safety

This is the "simple" variant of the list: it is *not* safe for concurrent
use.  If multiple goroutines access the list, protect it with a
`sync.Mutex`/`sync.RWMutex` of your own.
