= dqueue_ts — a thread safe generics based double ended queue (deque) on a doubly linked list

A generic double ended queue (deque) built on top of the generic doubly
linked list in `github.com/pschlump/pluto/dll_ts`.  The underlying list is
thread safe, so this deque is safe for concurrent use.

Elements can be inserted and removed at both ends of the queue.  Every
operation is strictly O(1) with no memory copy cost.  Elements are stored
as pointers: `PushFront`/`PushBack` take a `*T` and `PeekFront`/`PeekBack`/
`PopFront`/`PopBack` return a `*T`.  The element type must implement
`comparable.Equality`.

The zero value of `Deque[T]` is an empty queue ready to use.

== Operations

|===
| Operation                  | Description                                     | Complexity

| `PushFront(t)`             | Insert an element at the front                  | O(1)
| `PushBack(t)`              | Insert an element at the back                   | O(1)
| `PopFront()`               | Remove and return the front element             | O(1)
| `PopBack()`                | Remove and return the back element              | O(1)
| `PeekFront()`              | Return the front element without removing it    | O(1)
| `PeekBack()`               | Return the back element without removing it     | O(1)
| `IsEmpty()`                | True if the queue is empty                      | O(1)
| `Length()`                 | Number of elements                              | O(1)
| `Truncate()`               | Remove all elements                             | O(1)
| `All()` / `Backward()`     | Range-over-func iterators (front→back / back→front) | O(n)
|===

== Example

[source,go]
----
package main

import (
	"fmt"

	"github.com/pschlump/pluto/comparable"
	"github.com/pschlump/pluto/dqueue_ts"
)

type Item struct {
	Name string
}

func (a Item) IsEqual(x comparable.Equality) bool {
	b, ok := x.(Item)
	return ok && a.Name == b.Name
}

func main() {
	var q dqueue_ts.Deque[Item]
	q.PushBack(&Item{Name: "b"})
	q.PushFront(&Item{Name: "a"})
	q.PushBack(&Item{Name: "c"})

	for _, v := range q.All() {
		fmt.Println(v.Name) // a, b, c
	}

	v, err := q.PopBack() // v.Name = "c", err = nil
	_, _ = v, err
}
----

== Thread safety

This implementation is thread safe; all methods may be called concurrently
from multiple goroutines (the underlying `dll_ts` list guards every
operation with a `sync.RWMutex`).  `All` and `Backward` use the list's
thread safe step-at-a-time iterator: safe to use concurrently, but not a
consistent snapshot — elements pushed while iterating may be visited and
elements popped by another goroutine may be skipped.  Run the tests with
`go test -race` to validate usage.

== Notes

This package is a thin, deque-focused wrapper over `dll_ts`.  You can use
`dll_ts` directly, but this wrapper makes the intent — a double ended
queue — explicit.  Used only at one end, it behaves as a stack; used with
`PushBack`/`PopFront`, it behaves as a FIFO queue (see `../queue_dll_ts`).
Each element requires a node allocation; if that cost matters and the
queue is large, a slice based structure may be faster in practice.
