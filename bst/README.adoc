= bst — Ordered Collection (Binary Search Tree)
:toc:

Package `bst` implements an ordered collection of generic items as an
unbalanced binary search tree. Items must implement
`github.com/pschlump/pluto/comparable.Comparable` (a single `Compare` method).

Note: this package was formerly named `dag`; the data structure has always
been a binary search tree, and the package and type names now reflect that.
For a balanced alternative, see `avl_tree`.

== Complexity

The tree is not balanced, so the average-case `O(log n)` operations degrade
to `O(n)` when items are inserted in sorted order.

[cols="2,1,1,3",options="header"]
|===
| Operation                     | Average  | Worst case | Notes

| `Insert`                      | O(log n) | O(n)       | duplicate keys replace stored item
| `Search`                      | O(log n) | O(n)       | returns `nil` when not found
| `Delete`                      | O(log n) | O(n)       | returns `false` when not found
| `FindMin`/`FindMax`           | O(log n) | O(n)       |
| `DeleteAtHead`/`DeleteAtTail` | O(log n) | O(n)       | remove smallest/largest
| `IsEmpty`/`Length`            | O(1)     | O(1)       |
| `Truncate`                    | O(1)     | O(1)       | drops the whole tree
| `Depth`                       | O(n)     | O(n)       | nodes on longest root-to-leaf path
| `Index`                       | O(n)     | O(n)       | item at in-order position
| `Reverse`                     | O(n)     | O(n)       | mirrors the tree in place
| `Walk*`/`All`/`Backward`      | O(n)     | O(n)       | full traversal
|===

== Usage

[source,go]
----
package main

import (
	"fmt"

	"github.com/pschlump/pluto/comparable"
	"github.com/pschlump/pluto/bst"
)

type Item int

func (a Item) Compare(x comparable.Comparable) int {
	b := x.(Item)
	if a < b {
		return -1
	} else if a > b {
		return 1
	}
	return 0
}

func main() {
	var tree bst.BinarySearchTree[Item]

	tree.Insert(Item(5))
	tree.Insert(Item(2))
	tree.Insert(Item(9))

	if p := tree.Search(Item(2)); p != nil {
		fmt.Println("found", *p)
	}

	// Modern Go 1.23+ range-over-func iteration, ascending order:
	for v := range tree.All() {
		fmt.Println(v) // 2 5 9
	}
	// Descending order:
	for v := range tree.Backward() {
		fmt.Println(v) // 9 5 2
	}

	tree.Delete(Item(5))
	fmt.Println(tree.Length()) // 2
}
----

The older callback-based traversals (`WalkInOrder`, `WalkPreOrder`,
`WalkPostOrder`) are retained for compatibility; new code should prefer
`All()` and `Backward()`.

== Thread Safety

`BinarySearchTree` is *not* safe for concurrent use. If a tree is
shared between goroutines, all access must be guarded by an external mutex.
