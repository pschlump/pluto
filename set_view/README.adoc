= set_view

Live lazy read-only union, intersection, difference, and symmetric-difference
views over Pluto plain or thread-safe sets. Contains and All implement algebra
through operand membership; no auxiliary set is allocated. Duplicate values are
suppressed, early termination propagates, and later operand mutations are visible.

`Wrap` and `Filter` add explicit `MutableView` write-through behavior. Filtered
insert rejects excluded values with `ErrOutsideView`; deletion and truncation
affect only visible values. These views work with plain and `_ts` sets. Algebraic
views remain read-only because writing to their results would be ambiguous.
