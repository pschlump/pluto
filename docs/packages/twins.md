# _ts twins — mapping and lock discipline

- **Thread-safe `_ts` twins**: `binary_tree_ts` mirrors `binary_tree`, `avl_tree_ts` mirrors `avl_tree`, `rb_tree_ts` mirrors `rb_tree`, `interval_tree_ts` mirrors `interval_tree` (real `Lock`/`Unlock` + `Nl*` — see docs/packages/interval_tree.md), `skip_list_ts` mirrors `skip_list`, `dll_ts` mirrors `dll`, `sll_ts` mirrors `sll`, `queue_ts` mirrors `queue`, `bag_ts` mirrors `bag` (see docs/packages/bag.md), `stack_ts` mirrors `stack` (see docs/packages/stack.md), `heap_ts` mirrors `heap`, `priority_queue_ts` mirrors `priority_queue`, `heap_sort_ts` mirrors `heap_sort` (see docs/packages/heap_sort.md), `hash_grow_ts` mirrors `hash_grow`, `hash_tab_bt_ts` mirrors `hash_tab_bt`, `hash_tab_ts` mirrors `hash_tab`, `hash_tab_dll_ts` mirrors `hash_tab_dll`, and `cuckoo_ts` mirrors `cuckoo`, `union_find_ts` mirrors `union_find` (but its `Find`/`Connected` take the **write** lock — path halving mutates), `index_pq_ts` mirrors `index_pq`, and `graph_ts` mirrors `graph`, `digraph_ts` mirrors `digraph`, and `dijkstra_ts` mirrors `dijkstra` (see docs/packages/dijkstra.md), `mst_ts` mirrors `mst` and `bellman_ford_ts` mirrors `bellman_ford` and `floyd_warshall_ts` mirrors `floyd_warshall` (all three as query objects over the `dijkstra_ts` graph types — see their files under docs/packages), `fenwick_tree_ts` mirrors `fenwick_tree`, `segment_tree_ts` mirrors `segment_tree`, and `sparse_vector_ts` mirrors `sparse_vector` (its two-vector ops snapshot the operand under the operand's own lock — never two locks at once; see docs/packages/sparse_vector.md), `stream_ts` mirrors `stream` (see docs/packages/stream.md), `hyperloglog_ts` mirrors `hyperloglog` (see docs/packages/hyperloglog.md), `lfu_ts` mirrors `lfu` (see docs/packages/lfu.md), `lru_ts` mirrors `lru` (see docs/packages/lru.md — note `Get` takes the write lock there), and `bloom_ts` mirrors `bloom` (see docs/packages/bloom.md), each with the identical public API behind a `sync.RWMutex`; `stack_sll_ts` is the thread-safe LIFO stack on a singly linked list (see docs/packages/stack.md for why it is self-contained), `dqueue_ts` mirrors `dqueue` (see docs/packages/dqueue.md for the same self-contained rationale), and `quicklist_ts` mirrors `quicklist` (a wrapper over the plain package — see docs/packages/quicklist.md for which methods take the write lock), and `kd_tree_ts` mirrors `kd_tree` (a wrapper over the plain package — see docs/packages/kd_tree.md; `PointSet` has no twin), and the two set facades are wrapper twins the same way: `hash_set_ts` mirrors `hash_set` (see docs/packages/hash_set.md) and `tree_set_ts` mirrors `tree_set` (see docs/packages/tree_set.md).  `queue_dll` has no `_ts` twin (see docs/packages/queue_dll.md for where shared-FIFO callers go), and `suffix_array` has none either (see docs/packages/suffix_array.md — it is immutable after construction). The pure-algorithm packages `substring` (immutable query objects), `quick_sort`, `shell_sort`, `merge_sort`, `multiway_merge`, `string_sort`, `lzw`, `run_length`, `huffman` (stateless functions), `geo` (stateless functions), `bitmap` (stateless functions), and `maxflow`, `bipartite`, `assignment_problem`, `geometry`, and `global_mincut` (constructor snapshots, immutable results) likewise have no `_ts` twin — see their files under docs/packages. `trie_ts` mirrors `trie` and `tst_ts` mirrors `tst` (see docs/packages/trie.md and docs/packages/tst.md), and `patricia_trie_ts` mirrors `patricia_trie` (see docs/packages/patricia_trie.md).  Their `Front`/`All`/`Backward`/`IterateOver` iterate a snapshot taken under the read lock (safe to mutate while iterating) — the exceptions are the legacy `DllIter`/`SllIter` cursors in the list packages, which walk the live list under a per-call read lock; their walks and `Dump` hold the read lock for the whole traversal, so callbacks must not call methods on the same tree — and locked methods must not call other locked methods (use the lock-free internals instead; see `nodeDepth` in rb_tree_ts).  The `avl_tree_ts` set operations and `dll_ts`'s `Concat` snapshot operands under each operand's own read lock before taking the destination's write lock (no nested locks, operands may alias the destination).  When you change one package, change its twin.  Run `make race` after touching any `_ts` package.
