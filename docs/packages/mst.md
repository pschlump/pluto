# mst notes

`mst` is Sedgwick's §4.7–4.8 over `dijkstra.EdgeWeightedGraph` — four constructor-style immutable result objects with the same surface (`Edges() []dijkstra.Edge`, `Weight()`, `Len()`): `LazyPrimMST` composes `pluto/priority_queue`, eager `PrimMST` composes `pluto/index_pq` (decrease-key = `Change`), `KruskalMST` composes `pluto/union_find` with `slices.SortFunc`, and `BoruvkaMST` composes `pluto/union_find` again — four intra-pluto compositions on one borrowed container. Shared `checkGraph` enforces the 2-panic contract (nil or empty graph). Kruskal's edge gather filters `e.Other(v) >= v`, **not** `e.V <= e.W`: `EdgeWeightedGraph.AddEdge` stores edges un-normalized in both endpoints' lists, so a V>W filter would drop edges (tinyEWG has `6 2`); self-loop duplicates are harmless (UF already-connected skip). Any weights legal (negative edges fine — only the Dijkstra constructors reject negatives); disconnected input yields the minimum spanning forest (`Len == V - components`). Verified edge-for-edge vs algs4 tinyEWG (weight 1.81) and cross-checked four-ways plus an in-test brute-force Prim at seed 42. `mst_ts` takes `*dijkstra_ts.EdgeWeightedGraph` and snapshots per vertex via its `Adj` (each call a copy under the graph's read lock) — consistent per vertex, NOT an atomic whole-graph snapshot (dijkstra_ts exports none); results immutable.

Borůvka implementation traps: each round, every component records its cheapest **crossing** edge while scanning ALL adjacency lists (index the pick by the component root `r`, `uf.Find`); then union **after** the whole scan — unioning mid-scan would leave later `cheapest[r]` entries indexed by stale roots. Because both endpoints of one edge can be each other's cheapest pick, a merge attempt can find the components already joined; `Union` returning `false` is the skip (the reciprocal-pick test covers this). A `hasCheapest []bool` marker array is required — a zero-value `dijkstra.Edge` looks like a real edge, so `!hasCheapest[r]` must gate both the min-compare and the merge (dijkstra's `hasEdge` precedent). Self-loops are never crossing edges (`Other(v) == v`, same root). `Edges` returns merge order, NOT ascending weight order (the documented divergence from KruskalMST; the example demonstrates it). Benchmarked at V=4096, E=16384: Prim 1.32 ms, Kruskal 1.54 ms, Borůvka 1.85 ms, lazy Prim 3.09 ms — the full-adjacency scan per round costs more than the log-factor suggests at this size.
