# mst notes

`mst` is Sedgwick's §4.7–4.8 over `dijkstra.EdgeWeightedGraph` — three constructor-style immutable result objects with the same surface (`Edges() []dijkstra.Edge`, `Weight()`, `Len()`): `LazyPrimMST` composes `pluto/priority_queue`, eager `PrimMST` composes `pluto/index_pq` (decrease-key = `Change`), `KruskalMST` composes `pluto/union_find` with `slices.SortFunc` — three intra-pluto compositions on one borrowed container. Shared `checkGraph` enforces the 2-panic contract (nil or empty graph). Kruskal's edge gather filters `e.Other(v) >= v`, **not** `e.V <= e.W`: `EdgeWeightedGraph.AddEdge` stores edges un-normalized in both endpoints' lists, so a V>W filter would drop edges (tinyEWG has `6 2`); self-loop duplicates are harmless (UF already-connected skip). Any weights legal (negative edges fine — only the Dijkstra constructors reject negatives); disconnected input yields the minimum spanning forest (`Len == V - components`). Verified edge-for-edge vs algs4 tinyEWG (weight 1.81) and cross-checked three-ways plus an in-test brute-force Prim at seed 42. `mst_ts` takes `*dijkstra_ts.EdgeWeightedGraph` and snapshots per vertex via its `Adj` (each call a copy under the graph's read lock) — consistent per vertex, NOT an atomic whole-graph snapshot (dijkstra_ts exports none); results immutable.
