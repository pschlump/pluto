# bellman_ford notes

`bellman_ford` is Sedgwick's §4.10–4.11 over `dijkstra.EdgeWeightedDigraph` — shortest paths where dijkstra cannot go (negative weights). `BellmanFordSP` is the queue-based algs4 port (FIFO via `pluto/queue`, `onQueue []bool`, relax-count-amortized `findNegativeCycle` over the edgeTo subgraph every V relaxations, plus one belt-and-braces final scan after the queue drains); the constructor snapshots adjacency so the result is immutable. algs4 semantics kept: when a negative cycle is reachable from s, `DistTo`/`PathTo` **panic** naming the method (distances undefined) — `HasNegativeCycle`/`NegativeCycle` (cycle in cycle order, fresh slice) are the inspection API. `DistTo` returns bare float64 with `+Inf` (the dijkstra convention, not `(dist, ok)`). `AcyclicSP`/`AcyclicLP` (§4.10) relax in topological order via a small internal DFS (self-contained — deliberately does NOT import `pluto/digraph`); constructors panic on a cyclic digraph; LP reports `-Inf` for unreachable. Verified vs algs4 tinyEWD/tinyEWDn/tinyEWDAG (embedded literals) and against `dijkstra.NewDijkstraSP` on non-negative graphs; thorough_test.go cross-checks a naive relax-everything reference (no pluto imports) at seeds 42/43/44 including negative-cycle witness validation. `bellman_ford_ts` takes `*dijkstra_ts.EdgeWeightedDigraph` with the same per-vertex-snapshot atomicity caveat as `mst_ts`; the acyclic race hammer adds only lower→higher edges so every snapshot stays a DAG.
