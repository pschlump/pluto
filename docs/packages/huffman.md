# huffman notes

`huffman` is Sedgwick's §5.5 Huffman compression as stateless pure functions over `[]byte` (the lzw precedent — non-generic, **no panics at all**, `Expand` returns nil on malformed, no `_ts` twin), completing the §5.5 compression trio with lzw/run_length. Blob format: preorder trie (leaf = `1` bit + 8-bit symbol, internal = `0` bit), then a **64-bit** symbol count (NOT algs4's 32-bit Java int — Go slices exceed 4 GiB; this alone breaks wire compatibility, the comparison is semantic like lzw), then the codewords, MSB-first with the final partial byte zero-padded (the bitmap/lzw/run_length convention).

Contracts to preserve:

- **The merge composes `pluto/heap`** (`heap.NewHeapFunc` over `huffItem{freq int64, seq int, node *huffNode}`) with a `(freq, seq)` tie-break — leaves pushed in symbol order, merged subtrees in creation order, first pop = LEFT child — so the blob is **deterministic: recompressing an expansion reproduces the blob byte for byte** (asserted every round-trip iteration). Any tie-break is optimal; this one just makes output stable. Optimality is pinned by `refOptimalCost` in thorough_test.go — a structurally different scan-based two-smallest merge whose weighted path length Σfreq·len must equal the built code's for ANY tie-break, including all-equal-frequency tables where the shapes differ. The blob's parsed trie must satisfy Kraft's equality Σ2^-depth = 1, ≤256 leaves, full binary tree — checked from the parsed blob, not trusted from Compress.
- **A single distinct symbol ⇒ the trie is that leaf ⇒ the empty codeword ⇒ zero bits per symbol** (1 MiB of one byte → exactly 10 bytes, `TestSingleSymbolTenBytes`). Legal and pinned — and also the **documented decompression bomb**: a crafted single-leaf blob can claim any count and Expand allocates accordingly (`TestCountInflationIsLegal`; gzip/algs4 share the exposure). Under an internal root every codeword costs ≥ 1 bit, so a count exceeding the bits remaining is rejected — the provable bound, which also guarantees garbage decodes stay ≤ 8·len(blob) (`TestMalformedGarbage`).
- **Codewords are strings, not integers** — `buildCode` concatenates like algs4's String: 85 Fibonacci-weighted symbols (F(87) ≈ 6.8e17; the sequence must stop ≤ ~90 symbols or int64 overflows — a REAL past bug where wrapped values produced an impossible 106-bit code) yield an exactly-84-bit codeword, pinned by `TestFibonacciDeepCodes`. `TestDeepCodesExpand` pins 100-deep decode from a hand-built chain (Compress itself cannot exceed ~84-bit codes within int64 frequency sums). `readTrie` caps the trie at 511 nodes = 2·256−1, bounding recursion/allocation on hostile streams (algs4 recurses to stack exhaustion); the count guards are: high 32-bit half with top bit set → nil (no Go slice could hold it — this closed a REAL `makeslice: cap out of range` panic on all-0xFF blobs), plus the internal-root bits-remaining check.
- **Every strict prefix of a valid blob is malformed** (the writer never pads a whole byte) — `TestMalformedTruncation` sweeps every prefix of 5 inputs; trailing bytes after the last codeword are ignored (lzw behavior). Hand-traced byte-exact vectors in huffman_test.go (`"AB"` → `50 68 40 00×7 48`, plus AAA/AAB/X) pin the bit order and the tie-break — two of them caught trace typos during development; the implementation was right.
- **bits.go is deliberately duplicated from lzw** (the backlog's "duplicate small" option over lifting into g_lib): g_lib's charter is stateless pure functions and a bit writer is stateful machinery. huffman's copy adds `writeCode(string)` for '0'/'1' codewords. Decided once, noted in the READMEs — if a third consumer appears, lift into an `internal/` package instead.

`TestRandomizedRoundTrip` (PCG 42,7, 400 iters, six regimes: uniform256/binary/4-symbol/skew/runs/single) checks round-trip + recompress-identity + trie invariants each iteration. Benchmarks (1 MiB, M4 Max, README table): 0.33 B/byte on runs, 0.55 text, ~1.0 uniform, 10 bytes single; Compress 70–671 MB/s, Expand 22–1276 MB/s — Expand cost tracks total codeword bits, not output bytes.
