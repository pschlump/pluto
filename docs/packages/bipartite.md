# bipartite notes

`bipartite` is Sedgwick's §6.4 maximum bipartite matching (backlog Tier-2 item 13) — two constructor-style immutable query objects with ONE surface (the mst same-shape-alternatives precedent): `NewBipartiteMatching(g)` (Kuhn's recursive per-free-white augmenting paths, O(V·E)) and `NewHopcroftKarp(g)` (phased BFS layering + vertex-disjoint shortest augmenting DFS, O(E·√V)). Shared `matching` struct (`white []bool`, `mate []int`, `cardinality`, `inCover`); the bipartition IS `graph.NewTwoColor` (intra-pluto composition) with **side A = TwoColor's color false via inversion at load** (`m.white[v] = !c` — the DFS root's side; storing the color directly flips both sides and contradicts the [white, black] Edges contract). Both may return different partners for equal cardinality — document, don't assert equality of matchings.

**König's minimum vertex cover is the correctness certificate**: `computeCover` (stack-based Z-reachability from free whites along alternating non-matching edges, following the matched edge back; `inCover[v] = white[v] != inZ[v]` — whites∉Z ∪ blacks∈Z). `checkCertificate` in thorough_test.go proves maximality every run: symmetric mates over real edges, 2·cardinality matched vertices, cover touches every edge, |cover| == cardinality (a cover of matching size proves no larger matching). Plus `refMatching` (BFS Hungarian with explicit parent-link flips — structurally different from both) and a brute-force all-matchings oracle on small graphs.

**The Hopcroft–Karp livelock law** (a real past bug — keep the guard): in the phase DFS, a black vertex is marked `used` ONLY when an augmentation consumes it. Marking on exploration (failure) destroys the last shortest path — a failed sibling recursion poisons a black the parent still needs, the phase augments 0, the next BFS finds the same distFree forever. Failure prunes the WHITE (`dist[v] = unreachable`), never the black. This also bounds the phase at O(E): a failed white is never re-entered, and a succeeded white is unreachable (its new black is `used`, its old black was just re-paired to its parent). The BFS layers whites only (dist on white vertices; free blacks seen through `dist[v]+1 = distFree`); the DFS extends through a matched white only at `dist[u] == dist[v]+1 && dist[v]+1 < distFree` and completes at a free black only at exactly `== distFree`.

Direct integer augmentation was chosen over algs4's FordFulkerson composition per the backlog's "bench once, pick" — measured (M4 Max, README): direct beats maxflow-composition 6–35× (HK 146 µs vs maxflow 4.7 ms on 500×500 sparse), HK beats Kuhn 5–15×; `bench_test.go` carries `maxflowMatching` as the reference. Panic contract: exactly the non-bipartite graph (both ctors name themselves); nil/empty graphs → empty matching (NewCC precedent); nil results tolerate every read (pointer-method nil guards BEFORE touching `bm.m` — the field access itself segfaults on nil); out-of-range vertices report unmatched. Constructors snapshot the adjacency (`adjacency(g)`), results immutable → **no `_ts` twin** (maxflow precedent). Test details: chain graphs want **⌊n/2⌋**, not ⌊(n−1)/2⌋ (path on n vertices); the randomized suites run direct-constructed bipartite graphs AND random arbitrary graphs filtered through the real TwoColor (multi-component colorings).
