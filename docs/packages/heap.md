# heap notes

`Heap[T any]` is the min-heap (stdlib container/heap lineage — keep the Go Authors attribution in the header): stored comparator via `NewHeap[T cmp.Ordered]`/`NewHeapFunc` (reversed comparator ⇒ max-heap), value semantics, and the **indexed operations report `false` on out-of-range instead of panicking** (`Delete`, `Fix`, `SetValue`, `GetValue` all return bool; `Search` returns `(T, pos, bool)` with the `-1` sentinel — no vestigial always-nil err).  `All` yields **internal breadth-first order, not sorted order** — never assert sorted output from `All`; drain with `Pop` for sorted order.  `AppendHeap` bulk-appends unordered, then `Heapify` rebuilds (call it for `i = Len()/2-1` down to 0).  Panic contract: exactly 3 (`NewHeapFunc(nil)`, `Push`/`AppendHeap` on nil or zero-value).  `Pop`/`Delete` zero the slot and nil the slice on full drain.  No-op `Lock`/`Unlock` kept (heap_ts is the prospective twin).  `checkHeapInvariant` in heap_test.go verifies the parent≤children property — call it after structural changes.  `Dump` prints an indexed internal-order listing.

`heap_ts` is the twin with the `lock sync.RWMutex`: same tolerant index ops and 3-panic contract, eager value-snapshot `All`, and — unlike the plain package — **real `Lock`/`Unlock` plus the `Nl*` methods** (`NlLen`/`NlGetValue`/`NlPush`/`NlPop`/`NlDelete`/`NlFix`, the lock-free bodies `nlPop`/`nlDelete`/`nlFix`) for compound operations; calling a locked public method while holding `Lock` deadlocks.
