# run_length notes

`run_length` is Sedgwick's §5.5 RunLength as stateless pure functions over `[]byte` (the lzw precedent — non-generic, **no panics at all**, no `_ts` twin): `Compress(data []byte) []byte` / `Expand(blob []byte) []byte`. Bits are read MSB-first (the bitmap/lzw convention); the output is one count byte per run, runs **strictly alternating zero-bits/one-bits always starting with zero-bits** (input that opens with a 1-bit encodes a first count of 0 — the alternation anchor); a run longer than 255 bits splits as `255, 0, remainder` — the **eager** form of algs4's lazy toggle-at-256 encoder, decoded identically by the strictly-alternating reader (proven equivalent by hand-trace; the split's 0 count decodes to nothing and merely restores the alternation). `Expand` returns nil iff the counts do not sum to a whole number of bytes (the ONLY failure mode, never a panic); interior/trailing zero counts are tolerated (decode to no bits) though only Compress's output is canonical — a 0 appears only at index 0 or immediately after a 255 (`TestCanonicalForm`); empty ↔ empty in both directions. Known vectors in run_length_test.go hand-traced from the bit stream (`0xF0`→`[0,4,4]`, `0x55`→eight 1s, `0xAA`→`[0,1×8]`, 32×`0x00`→`[255,0,1]`, 33×`0x00`→`[255,0,9]`); `TestRandomizedRoundTrip` (PCG 42,7) sweeps sizes 0..600 × four input regimes (uniform random, long alternating 0x00/0xFF runs, sparse single bits, per-byte 00/FF mix) checking round-trip AND count totals == 8·len; `TestMalformedSweep` verifies nil ⟺ total%8≠0 over 2000 random blobs; `TestSingleByteSweep` covers all 256 single bytes.
