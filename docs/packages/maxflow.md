# maxflow notes

`maxflow` is Sedgwick's §6.4 max-flow / min-cut over float64 capacities (the dijkstra weight precedent; integer capacities stay exact under float64 summation — the bench harness depends on it). `FlowEdge{From, To int; Capacity, Flow float64}` (exported read-only-by-convention fields, the dijkstra.Edge precedent) with `Other`/`ResidualCapacityTo`/`AddResidualFlowTo` (panics, leaving the edge unchanged, on negative/NaN delta or flow leaving [0, Capacity]). `FlowNetwork` (vertices `0..n-1`): `NewFlowNetwork(v)` panics on v < 1; `AddEdge` **mirrors `dijkstra.EdgeWeightedDigraph.AddEdge` exactly** — false on out-of-range endpoints, panic on nil network — plus panic on negative/NaN capacity; parallel edges and self-loops allowed (self-loops count once in `E`, appear twice in `Adj`); each edge lives in BOTH endpoints' adjacency lists (residual traversal; algs4 does the same); `Adj` returns the live internal slice (documented, like dijkstra). `NewFordFulkerson(g, s, t)` is Edmonds-Karp (BFS shortest augmenting path on `pluto/queue`, intra-pluto composition) over a **private deep copy** of the edges — the caller's network is never mutated (snapshot precedent; algs4 mutates it), result immutable: `Value()`/`InMinCut(v)`/`S()`/`T()`/`Edges()` (fresh copy with computed flows). Panics name the constructor: nil/empty network, out-of-range s/t, s == t; nil result reports 0/false/-1. No epsilon rounding anywhere (algs4 has 1e-10) — exact arithmetic. Documented algs4 bug: `FlowNetwork.edges()` silently drops self-loops; pluto's `Edges()` returns them. No `_ts` twin (immutable results, suffix_array precedent). `thorough_test.go` verifies by CERTIFICATE (capacity constraints, conservation, s-outflow == Value, InMinCut cut capacity == Value exactly) and by a BRUTE-FORCE all-2^(V-2)-cuts oracle on V ≤ 12 random networks at seeds 42–45, plus the tinyFN fixture (value 4, independently confirmed by the oracle — the /data/ URL 404s, it lives at /64maxflow/tinyFN.txt).
