# kd_tree notes

`kd_tree.KdTree` is the 2-d k-d tree (backlog §3.4; algs4 "5. Nearest Neighbor Search" `KdTree.java`) over the `g_lib.Point2D`/`RectHV` value types (introduced with it in `g_lib/point2d.go` for the Tier-2 geometry batch). Alternating x/y split by depth (even = x): strictly-less goes left, ties/greater right; duplicate caught by `==` along its own path; nodes carry **no stored RectHV** — `splitRects` derives each subtree rectangle from the ancestor split during the descent (four floats down the recursion instead of stored per node); the root rect is the **whole plane ±Inf**, not algs4's unit square. **Constructor-free** (the tries' precedent — the splitting rule is inherent in the coordinates, no comparison function to store; `NewKdTree()` is convenience only), set semantics (`Insert` returns added-vs-duplicate), unbalanced (binary_tree precedent — a monotone diagonal legitimately builds a depth-n chain, asserted in `TestDegenerateChain`; random order stays ~2·ln n, `TestShuffledUniformDepth`), **no delete** (as in algs4 — rebuild instead). Panic contract: exactly 2 per structure (`Insert` on nil, `Insert` with a NaN coordinate — the interval_tree reject-at-write precedent); ±Inf coordinates are legal points (squared distances saturate to +Inf — at ~1e300 scale ties at Inf are possible, the tests use 1e150), NaN probes never panic (unspecified answers).

Queries: `Nearest` = champion + prune `rect.DistanceSquaredTo(q) > champD2` (strict), near-side-first descent; `NearestK(q, k)` = the same with a **bounded max-heap composed from pluto/heap** (`NewHeapFunc` with a reversed comparator on `kdBest{p, d2}`), pruning when full && rectD2 > worst.d2, final deterministic sort by (d2, X, Y) — beyond the algs4 surface (it grades `nearest` only). Everything measures **squared** distance. Tie contract: among exactly equidistant points which one `Nearest` returns / which make `NearestK`'s cut is unspecified, but the **distance sequence is exact** — the model tests compare distance sequences, never point identity, and beware that mathematically-tied distances can differ by an ulp (the fixture's C=0.1 vs D=0.09999999999999995 — both structures compute identical d² so their orders agree). `Range` collects where the closed rect contains, recursing only where it intersects (tree order output — sort by (X,Y) when order matters). `All` is a preorder live walk.

`kd_tree.PointSet` is algs4 `PointSET` shipped publicly (map-backed brute force, O(n) queries) — doubling as the test oracle (the way the assignment pairs the two); its `All` order is map-randomized, documented. `checkInvariants` in thorough_test.go (every node inside its rect, strict partition by depth parity, no duplicates, count == Len, Contains hits all); `TestKdTreeRandomizedModel` (PCG 42,7, 4000 steps) cross-checks every query against PointSet with tie-legal checks; `TestNearestTies` (unit-axis integer d²), `TestDegenerateChain`, `TestShuffledUniformDepth` (10k points, depth ≤ 4·log₂ n), `TestRangeEdgeRects` (zero-width/point/inverted/whole-plane). Benchmarks (100k points, M4 Max): Build 14.5 ms, Contains 22 ns, Nearest 925 ns, NearestK 3.4 µs, Range 777 ns vs PointSet Nearest 466 µs (~500×), Range 664 µs (~850×), NearestK 10.4 ms (~3,000×).

`kd_tree_ts` is the **wrapper twin** (the stream_ts/hash_tab_bt_ts pattern — a plain `kd_tree.KdTree` value + one RWMutex, NOT a copy twin: nothing is stored to adopt or snapshot), aliases `Point2D`/`RectHV` (twin-switching = import change), nil guards before lock acquisition, `kd_tree_ts:`-prefixed write panics (a NaN through `NlInsert` carries the plain `kd_tree:` prefix — only the locking path pre-checks), eager-snapshot `All` (collect the plain live iterator under RLock, then serve the slice — inverted contract, `TestIteratorSnapshotSemantics`), and the full `Nl*` mirror (`NlInsert`/`NlLen`/`NlIsEmpty`/`NlContains`/`NlNearest`/`NlNearestK`/`NlRange` — plain inner calls). The canonical compound is check-spacing-then-insert (`Lock` + `NlNearest` + `NlInsert` + `Unlock`, `ExampleKdTree_Lock`); `TestKdTreeConstrainedInsertCompound` races it against plain writers and verifies pairwise spacing post-storm. **PointSet is deliberately NOT mirrored** (a locked linear scan is just a worse hash set). Race coverage: `TestKdTreeConcurrent` (8 writers × 500 + 4 readers on every read path, exact final count) and `TestKdTreeVsPlainModel` (fixed-seed behavioral identity with the plain package).
