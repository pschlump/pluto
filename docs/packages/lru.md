# lru notes

`Lru[K comparable, V any]` is a generic capacity-bounded LRU cache on `container/list` + map: `NewLru[K comparable, V any](capacity)` (panics on capacity < 1) and `NewLruFunc(capacity, evictable func(K, V) bool)` where the callback VETOES eviction (false = skip, try next-older; nil = all evictable). `Get` promotes, `Peek` doesn't (pin against eviction with Get), `Put` evicts down to capacity BEFORE inserting (a fresh entry is never its own victim) and, when everything is vetoed, temporarily EXCEEDS capacity — the soft cap `b_tree_disk_ts` depends on (dirty/flushing/pinned blocks are unevictable); document, don't "fix". `All`/`Backward` are `iter.Seq2[K, V]` (MRU→LRU / LRU→MRU; single-variable range yields the KEY) walking the **live** list. Nil/zero-value caches tolerate reads; `Put` on nil/zero-value panics (no capacity — no sane answer). Not safe for concurrent use; no-op `Lock`/`Unlock` kept for `lru_ts` parity. thorough_test.go's 10k-step model test (seed 42) verifies contents AND full recency order every step, plus a randomized veto test proving vetoed keys are never evicted.

`lru_ts` (request `note/06-lru-ts.md`, built for Ultima's `allkeys-lru`/`volatile-lru`, one cache per shard) wraps `*lru.Lru` behind one RWMutex (the stream_ts/lfu_ts composition pattern; plain lru unchanged except the additive no-op `Lock`/`Unlock` and doc updates). The lock split to remember: **`Get` takes the WRITE lock** — a hit re-marks recency, a mutation (`Peek`/`Len`/`Capacity` read-lock; `Put`/`Delete`/`Clear` write-lock) — measured ~7 ns lock overhead uncontended, and at 8 goroutines Get serializes (~135 ns) while Peek readers share (~86 ns). `All`/`Backward` are **eager snapshots** materialized under the read lock at call time (O(n) space, inverted from the plain live-list walk) — safe to mutate from inside the loop, tested by `TestIteratorSnapshotSemantics`. The veto callback runs **while the write lock is held** — documented prominently: no calling back into the cache (deadlock); no no-lock handle is passed to it (the note's optional escape hatch, declined — it cannot be done without weakening the lock discipline; the escape hatch is caller-held `Lock` + `Nl*`). Real `Lock`/`Unlock` + `NlGet`/`NlPeek`/`NlPut`/`NlDelete`/`NlClear`/`NlLen`/`NlCapacity` (no Nl iterators); the canonical compound is the atomic batch put with eviction-to-capacity (`TestConcurrentEvictToCap` gates never-above-cap + no-deadlock from 8 goroutines; `TestLockNlSoftCapEvict` covers the soft-cap flush). lru_ts_test.go ports every plain test (behavioral identity, identical model-test seed); panic contract is the plain 3 with `lru_ts:` prefixes. Race coverage in thorough_test.go (run `-race`).
