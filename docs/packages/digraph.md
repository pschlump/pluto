# digraph notes

`digraph` is Sedgwick's §4.4–4.6 directed graph on int vertices `0..n-1` — the directed sibling of `graph`, same `[][]int` adjacency with self-loops/parallel edges allowed and no `RemoveEdge`, plus a maintained `indeg []int` so `InDegree` is O(1) alongside `OutDegree` (Σout = Σin = E is a checked invariant). `Reverse()` flips all edges (Kosaraju's building block). Query objects in the same package, one file each: `DirectedDFS` (multi-source reachability — `Marked`/`Count`; zero sources panics), `DFSDirectedPaths`/`BFSDirectedPaths` (`HasPathTo`/source-first `PathTo`; BFS adds `DistTo` and uses `pluto/queue`), `DirectedCycle` (`HasCycle`/`Cycle` — on-stack DFS marking; self-loop reported as `[v v]`), `DepthFirstOrder` (`Pre`/`Post`/`ReversePost`), `Topological` (`HasOrder`/`Order` = DirectedCycle + reverse postorder) and `KosarajuSCC` (`StronglyConnected`/`ID`/`Count`), plus `TransitiveClosure` in `closure.go` (algs4 `TransitiveClosure`: one DFS per vertex into a V×V boolean reachability matrix — O(V·(V+E)) time, O(V²) memory, the sparse-friendly alternative to Warshall's O(V³); every vertex reaches itself; `Reachable(v, w)` is O(1), out-of-range/nil → false; the reused-`marked`-scratch detail: `clear(marked)` between passes). Sourced constructors panic on nil/empty graph or out-of-range source; the source-less queries (`DirectedCycle`/`DepthFirstOrder`/`Topological`/`KosarajuSCC`/`TransitiveClosure`) tolerate nil/empty graphs — the `NewCC` precedent (empty digraph has a sane answer). Verified against algs4 tinyDG/tinyDAG (embedded literals with source URLs): tinyDG has 5 SCCs. `digraph_ts` follows the `graph_ts` pattern exactly (snapshot `Adj`, `snapshotAdj()` deep copy under the read lock, traversals lock-free on the snapshot).

The SCC batch adds two more single-pass algorithms with the identical query surface (`StronglyConnected`/`ID`/`Count`, same nil/empty tolerance): `TarjanSCC` (tarjan_scc.go, algs4 `TarjanSCC` — low-link DFS, one pass, no reverse graph) and `GabowSCC` (gabow_scc.go, algs4 `GabowSCC` — path-based: path stack + boundary stack instead of low-links). Three port details matter. (1) Tarjan's `low[w]` is read *unconditionally* in the neighbor loop — algs4 sets `low[w] = V` when w's component closes, so a closed vertex can never lower a later minimum; don't add an on-stack guard, the sentinel is the whole trick. (2) Gabow's root test is `stack2.top == v` after the edge loop (v was retired as a boundary iff some descendant found a shallower path), and the boundary pops run only for `marked[w] && id[w] == -1` — w on the current path; stack2 can never empty mid-DFS (the tree root has the tree's minimum preorder), so the unguarded top read is safe. (3) The three algorithms assign component **ids in different orders** (Kosaraju by reverse-graph roots, Tarjan/Gabow by DFS retreat order) — `scc_cross_test.go` canonicalizes (sorted component vertex lists, then sorted) before comparing; comparing raw ids across algorithms is the classic false-failure. Benchmarked at n=1000/m=5000 random: Tarjan ≈ 20µs, Gabow ≈ 23µs, Kosaraju ≈ 97µs (it pays for `Reverse()` + the order object) — same O(V+E), ~5× constant-factor difference.

The Eulerian batch adds `DirectedEulerianCycle` and `DirectedEulerianPath` (eulerian.go, algs4 `DirectedEulerianCycle`/`DirectedEulerianPath`) — Hierholzer's algorithm as an iterative cursor walk (`directedWalk`): pop a vertex, follow unused out-edges via per-vertex cursors into `adj` (never mutating it), emit when stuck, then reverse the emission — the reversed stuck-order is the walk order. The E+1 length check is the connectivity oracle: a balanced-but-disconnected digraph's walk covers only one component, so the check subsumes any explicit SCC test (algs4 skips the SCC call for the same reason). The path constructor checks `deficit` = Σ positive (out-in) ≤ 1 (with Σ(out-in)=0 that also bounds the surplus-in vertices to one). E==0 → no walk (algs4 convention, documented); a lone self-loop is a legal 1-edge cycle `[v v]`. Tests verify by *certificate* (every consecutive pair an actual edge instance of the input multiset, each instance consumed exactly once, cycle closed) against independent textbook existence oracles (balance + weak connectivity via union-find) over 400 fixed-seed random digraphs, plus tinyDG (no Eulerian anything) and curated degenerates.
