# digraph notes

`digraph` is Sedgwick's §4.4–4.6 directed graph on int vertices `0..n-1` — the directed sibling of `graph`, same `[][]int` adjacency with self-loops/parallel edges allowed and no `RemoveEdge`, plus a maintained `indeg []int` so `InDegree` is O(1) alongside `OutDegree` (Σout = Σin = E is a checked invariant). `Reverse()` flips all edges (Kosaraju's building block). Query objects in the same package, one file each: `DirectedDFS` (multi-source reachability — `Marked`/`Count`; zero sources panics), `DFSDirectedPaths`/`BFSDirectedPaths` (`HasPathTo`/source-first `PathTo`; BFS adds `DistTo` and uses `pluto/queue`), `DirectedCycle` (`HasCycle`/`Cycle` — on-stack DFS marking; self-loop reported as `[v v]`), `DepthFirstOrder` (`Pre`/`Post`/`ReversePost`), `Topological` (`HasOrder`/`Order` = DirectedCycle + reverse postorder) and `KosarajuSCC` (`StronglyConnected`/`ID`/`Count`), plus `TransitiveClosure` in `closure.go` (algs4 `TransitiveClosure`: one DFS per vertex into a V×V boolean reachability matrix — O(V·(V+E)) time, O(V²) memory, the sparse-friendly alternative to Warshall's O(V³); every vertex reaches itself; `Reachable(v, w)` is O(1), out-of-range/nil → false; the reused-`marked`-scratch detail: `clear(marked)` between passes). Sourced constructors panic on nil/empty graph or out-of-range source; the source-less queries (`DirectedCycle`/`DepthFirstOrder`/`Topological`/`KosarajuSCC`/`TransitiveClosure`) tolerate nil/empty graphs — the `NewCC` precedent (empty digraph has a sane answer). Verified against algs4 tinyDG/tinyDAG (embedded literals with source URLs): tinyDG has 5 SCCs. `digraph_ts` follows the `graph_ts` pattern exactly (snapshot `Adj`, `snapshotAdj()` deep copy under the read lock, traversals lock-free on the snapshot).
