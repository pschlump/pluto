# index_pq notes

`IndexPQ[T any]` is Sedgwick's §2.6 IndexMinPQ — **self-contained, not composed on pluto/heap**, because the inverse position map `qp []int` (index → heap position, -1 absent) must be maintained inside `swim`/`sink`, which heap does not expose (the stack_sll_ts/dqueue self-contained rationale). Two-constructor ordering like heap (`NewIndexPQ[T cmp.Ordered](n)` / `NewIndexPQFunc(n, fx)`; max-PQ via a reversed fx); the index space `0..n-1` is fixed at construction. `Insert(k, v)` **replaces** the value of a present k (the trees' duplicates-replace convention) and returns true for any in-range k; `Change` returns false when k is absent. `Peek`/`Pop` return `(k, v, ok)`. `All` drains a private `clone()` snapshot in priority order (the priority_queue.All pattern). Panic contract: exactly 4 (nil cmp, `n < 1`, `Insert`/`Change` on nil or zero-value). `index_pq_ts` adds the lock, a snapshot `All` (clone under the read lock, drained lock-free), and the real `Lock`/`Unlock` + `Nl*` surface (`NlLen`/`NlContains`/`NlValue`/`NlInsert`/`NlChange`/`NlDelete`/`NlPop`). `checkInvariants` in thorough_test.go verifies the heap property over `pq`, `qp[pq[i]] == i`, and length == count of present indices — call it after structural changes.

**Phase-5 capabilities** (`capabilities.go`, plan §4.5 heaps/PQ menu) — the **map-shaped exception** among the §4.5 packages: `Slice`, `String`/`StringFunc`, `Equal`, `Clone` with map semantics, since the content is the set of index→value bindings.  `Slice` returns the VALUES in **backing order** — `vals[pq[i]]` over the breadth-first index heap, NOT priority order (`All` owns priority order; Insert (0,5),(1,3),(2,4) → `[3 5 4]`); O(n), nil→nil, empty→empty-non-nil.  `Equal` is **binding equality, not multiset equality**: length check, then every receiver index must be present in other with a `cmp==0` value — O(n), no sorting anywhere; **a value swap between indices keeps the multiset but changes the content → NOT equal** (swap test); the index space is capacity, not content (different `n`, same bindings → equal); comparator-based, never Go's `==`; consistent-comparator precondition documented.  `Clone` **rebuilds the bindings pair by pair** — `NewIndexPQFunc(q.n, q.cmp)` + `Insert` each (O(n log n)); a zero-value queue (`cmp == nil`) clones to a fresh zero value, since a constructor call would need `n ≥ 1`.  All total functions.  The `index_pq_ts` twin: `Slice` snapshots under the read lock; `Equal` snapshots the receiver's bindings under its own read lock, then reads other **one `Value` call at a time** (never two locks — deadlock-free in opposite directions); `Clone` snapshots under the read lock then rebuilds locally; no new `Nl*` (self-locking, not compounds).  Tests: `capabilities_test.go` (exact backing-order Slice, the swap-not-equal proof, different-value/different-length negatives, different-n-same-bindings equal, tie values, reversed comparator, 800-step PCG(1,42) map model with `checkInvariants` + `checkCapModel` every 37 steps — in the ts twin `checkInvariants` is called BARE, never under `q.Lock()`: it reads internals directly and calls the self-locking `Len`, so wrapping it in the write lock self-deadlocks (the package's thorough_test.go single-goroutine convention) — shuffled-rebuild-must-be-equal finish) and `capabilities_example_test.go`; the twin adds `TestCapabilitiesConcurrent` + `TestCapabilitiesEqualNoDeadlock` (n=500, same bindings built in reverse order).
