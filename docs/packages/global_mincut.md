# global_mincut notes

`global_mincut` is Sedgwick §6.4's global minimum cut as one query object, `NewGlobalMincut(g *dijkstra.EdgeWeightedGraph)` — the mst precedent for the container (intra-pluto composition over dijkstra's undirected weighted graph; mst's doc comment says exactly this). Stoer–Wagner, the matrix form: O(V³) time, O(V²) space, V−1 merge phases each running a maximum-adjacency search over the active super-vertices; the last vertex t of each phase yields the phase cut (t's group alone vs the rest, weight = its accumulated connection `conn[t]`), and the minimum phase cut is the answer. The phase loop runs `for phase := 1; phase < n; phase++` with `live := n - phase + 1` active vertices — an easy off-by-one (`n - phase` instead): it skips the full first-phase search and ends with a degenerate live==1 phase; the two-triangle bridge test catches it (returns 21 instead of 1). Tie-breaking: the MAS pick scan uses strict `conn[v] > conn[pick]`, keeping the SMALLEST id on ties → deterministic output for a fixed graph (documented; the example pins the chosen side of a tied cut — the OTHER triangle of the two-triangle bridge graph, both weight 1). Result surface: `Weight()` (0 for disconnected graphs — a component side is a weight-0 cut — and for n==1), `Cut()` (sorted side, nil only when no bipartition exists: n==1 or nil), `InCut(v)` (false out of range). Panic contract: nil/empty graph (a zero-value `dijkstra.EdgeWeightedGraph` has V==0 — the reachable "empty" case, since `NewEdgeWeightedGraph(0)` panics in dijkstra), and non-finite/negative weights naming the edge — NaN is rejected EXPLICITLY (`e.Weight < 0` is false for NaN, dijkstra's validate passes NaN through; here both bounds are checked, the floyd_warshall finite-only precedent). Parallel edges sum into the matrix (capacity semantics); self-loops are skipped in the build (never cross a cut). No `_ts` twin (immutable result, suffix_array/maxflow precedent).

Oracles: an all-bipartitions brute force (subsets containing 0, complement NONEMPTY — the all-ones mask would report weight 0 spuriously; bound is `mask < 1<<(n-1)-1`) over 400 fixed-seed random graphs n∈[2,11] with integer weights (exact float equality), each result also verified by CERTIFICATE (the returned side is nonempty proper, recomputed crossing weight == Weight(), InCut agrees with Cut); plus 12 medium graphs (n=30) cross-checked against the n−1-maxflows route — each undirected edge added BOTH directions into a `maxflow.FlowNetwork`, min over sinks of `NewFordFulkerson(net, 0, t).Value()` — two independent algorithm families agreeing exactly. The backlog's "pick after benchmark" is settled with measured numbers in bench_test.go's comment: Stoer–Wagner ~300µs at n=60 vs 1.7ms for the max-flow route (5.7×), 4.2ms vs 12.8ms at n=150 (3×) — the max-flow route's cost is dominated by constructing n−1 FlowNetworks (40MB/372k allocs at n=150) — so Stoer–Wagner is the implementation and the max-flow route stays as the test oracle. Scaling: cubic as advertised (301µs → 4.2ms → 74ms at n=60/150/400).
