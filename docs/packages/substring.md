# substring notes

`substring` is Sedgwick's §5.3 substring search: three constructor-style, immutable, compile-once/search-many query objects over byte strings — `NewKMP` (DFA `[256][]int`, guaranteed O(n+m)), `NewBoyerMoore` (bad-character rule only, like algs4 — no strong good-suffix rule), `NewRabinKarp` (rolling hash mod fixed prime 2³¹−1, **Las Vegas**: verifies byte-for-byte on every hash hit — algs4's published version is the Monte Carlo variant with a random per-run prime and no verification; also its `RabinKarp(char[], int)` constructor literally throws UnsupportedOperationException — documented algs4 bugs). `Search(text) int` returns the leftmost byte index or **-1** (the `strings.Index` convention — algs4 returns n on a miss); empty pattern → 0 (algs4's KMP crashes on it); nil receiver → -1; **no panics at all**. No `_ts` twin (immutable — suffix_array precedent). `thorough_test.go` cross-checks all three against stdlib `strings.Index` (an independent oracle) at fixed seed 42 over a 3-letter alphabet (forces partial matches) plus a binary {0x00, 0xFF} alphabet.
