# binomial_queue notes

`BinomialQueue[T any]` is Sedgwick's §9 binomial queue: a forest of min-heap-ordered binomial trees (at most one tree per degree, degrees strictly increasing) held as a `[]*bqNode[T]` root slice with per-node children slices. `Merge` is binary addition over the two forests with tree-linking as the carry — O(log n), the structure's signature operation; it absorbs and empties `other`, no-ops on empty/nil/self-merge, and a zero-value receiver adopts `other`'s cmp (the avl_tree `adoptCmp` pattern). `Insert` is a 1-node merge (amortized O(1), worst O(log n)); `DeleteMin` detaches the min root and merges its children (already a valid forest) back, O(log n); `FindMin`/`Peek` scan the ≤ log₂ n + 1 roots — no cached min pointer, documented O(log n). `All`/`Backward` are `iter.Seq2[int, T]` over the **live forest in internal order — NOT sorted**; document, don't assert. Panic contract is exactly 3: nil cmp at construction, `Insert` on nil/zero-value, `Merge` on a nil receiver with a non-empty other. `checkInvariants` in thorough_test.go (strictly increasing degrees, each tree a true 2ᵏ-node min-heap-ordered binomial tree, node count == Length) — call it after structural changes; the 800-step model test (`rand.NewSource(42)`) verifies true-minimum `DeleteMin` and multiset equality every step. No `_ts` twin.
