# hashing

## Contract and complexity

`HashCode` owns immutable bytes and a `LittleEndian`/`BigEndian` interpretation.
Construction, `Bytes`, and bounded copies never expose internal storage.
`AsUint32`/`AsUint64` require enough bytes; `PadToUint64` zero-extends. Ordered
combining uses Guava's byte-wise `x*37 ^ next`; unordered uses modular addition.
`ConsistentHash` implements the pinned LCG jump algorithm and panics for buckets
<= 0.

`HashFunction` supplies direct byte/string hashing and independent `Hasher`
values. `Hasher` writes primitives little-endian and strings as UTF-8 without an
implicit delimiter. `Funnel[T]` is a typed function into `PrimitiveSink`; length
prefixing avoids concatenation ambiguity. The shared hasher currently buffers
input, so streaming calls use O(input) memory and direct `HashBytes` is the
allocation-conscious path. All final hashes are chunk-independent.

Murmur3-32/128 (optional seed), SipHash-2-4 (Guava default or explicit key),
FarmHashFingerprint64, and Fingerprint2011 match Guava byte-for-byte. CRC32,
CRC32C, Adler32, MD5, SHA-1, SHA-256, and SHA-512 wrap the standard library.
MD5/SHA-1 are interoperability-only; none is a password hash.

## Verification

`hashing/testdata/guava_vectors.json` is generated by the pinned Java oracle.
It covers empty, 1/2/3/4-byte tails, 16/64-bit algorithm blocks, long inputs,
signed byte values, UTF-8 supplementary characters, and nonzero seeds. Tests
replay every vector with six chunk sizes, primitive writes, funnel framing,
combining, bucket boundaries, and minimal remapping. FarmHash/Fingerprint2011
are behavioral ports with Guava Apache-2.0 attribution retained in source.
No `_ts` twin is needed: functions and completed hash codes support concurrent
use; an individual Hasher is mutable and must not be shared.

Matched Go/JMH measurements and accuracy notes are in `docs/benchmarks/hashing/`.
