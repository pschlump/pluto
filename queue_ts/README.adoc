= queue_ts

A generic slice-backed *FIFO queue* that is *safe for concurrent use*
— the thread-safe twin of link:../queue/[pluto/queue].  Every operation is
guarded by a `sync.RWMutex`: readers run in parallel with each other,
writers are exclusive.

Like `queue`, the element type needs *no constraints at all* and the
zero value is an empty queue ready to use without a constructor.
`Dequeue` and `Peek` return `(T, error)` — an independent copy taken
under the lock, never a pointer into the queue's internals.

== Locking behavior

* *Reads* (`Peek`, `Len`, `Length`, `IsEmpty`) take the read lock and
release it before returning — they can run in parallel with each other.
* *Writes* (`Push`, `Enqueue`, `Pop`, `Dequeue`, `Truncate`) take the
write lock.
* *`All` and `Backward` operate on a snapshot* copied under the read
lock when they are called (one O(n) copy).  It is safe to mutate the
queue while iterating — including from inside the loop — and an
iterator never observes modifications made after it was created.

[source,go]
----
for _, v := range q.All() {
    q.Pop() // safe: All walks a snapshot
    _ = v
}
----

== Errors and panics

Identical to `queue`: `ErrEmptyQueue` (compare with `errors.Is`) reports
the empty queue, and the package has exactly *one* panic:

[options="header"]
|===
| Call                            | Why

| `Push`/`Enqueue` on a nil queue | a nil queue cannot store an element
|===

Everything else — including the zero value, which is fully usable because
there is no comparison or equality function to configure — tolerates a
nil queue as an empty queue.

== Usage

[source,go]
----
package main

import (
    "fmt"
    "sync"

    "github.com/pschlump/pluto/queue_ts"
)

func main() {
    var q queue_ts.Queue[int]

    // Producers from many goroutines share one queue.
    var wg sync.WaitGroup
    for p := 0; p < 8; p++ {
        wg.Add(1)
        go func(p int) {
            defer wg.Done()
            for i := 0; i < 100; i++ {
                q.Enqueue(p*1000 + i)
            }
        }(p)
    }
    wg.Wait()
    fmt.Println(q.Len()) // 800

    // Consumers drain it.
    for !q.IsEmpty() {
        if _, err := q.Dequeue(); err != nil {
            break
        }
    }
    fmt.Println(q.IsEmpty()) // true
}
----
